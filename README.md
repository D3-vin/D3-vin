### 👨‍💻 About
- Build networked software in **Python** and **Go**: async REST services, API integrations, protocol adapters, cross-platform CLI tools.
- Automation at heart: browser automation (Playwright), computer vision (OpenCV), system-level tooling (psutil, WinAPI).
- Like small tools with engineering culture: single-binary builds, embedded web dashboards, tidy TUIs, failure tolerance out of the box.

### 🧭 What I do
- Async backend services and REST APIs (Python/Quart, Go/net-http) with SSE streaming, proxies and gateways.
- Integration gateways between API protocols (OpenAI/Anthropic-compatible): token pools, retry / failover / auto-rotation.
- Browser and desktop automation, Telegram bots, cross-platform utilities with embedded web UI.
- Network-level tooling: TLS fingerprints (uTLS, curl_cffi), HTTP/3 (QUIC), WebSocket, SOCKS.
