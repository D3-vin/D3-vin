### 👨‍💻 Обо мне
- Пишу сетевое ПО на **Python** и **Go**: асинхронные REST-сервисы, интеграции с внешними API, протокольные адаптеры, кросс-платформенные CLI-инструменты.
- Автоматизация — моя стихия: браузер (Playwright), компьютерное зрение (OpenCV), системный уровень (psutil, WinAPI).
- Люблю маленькие инструменты с инженерной культурой: single-binary сборки, встроенные web-дашборды, аккуратные TUI, отказоустойчивость из коробки.

### 🧭 Чем занимаюсь
- Асинхронные бэкенд-сервисы и REST API (Python/Quart, Go/net-http): SSE-стриминг, прокси, шлюзы.
- Интеграционные шлюзы между API-протоколами (OpenAI/Anthropic-совместимые): пулы токенов, retry / failover / авторотация.
- Автоматизация браузера и десктопа, Telegram-боты, кросс-платформенные утилиты со встроенным web UI.
- Работа с сетевым уровнем: TLS-отпечатки (uTLS, curl_cffi), HTTP/3 (QUIC), WebSocket, SOCKS.
